# UI & UX Standards

Version: 1.0

---

# Purpose

This document defines the user interface and user experience standards for NachoFamilyApp.

The application is primarily used outdoors, inside amusement parks, by families with children.

The UI must therefore be simple, fast and intuitive.

---

Navigation should always be predictable.

Primary navigation should never require more than two taps.

Avoid deep navigation trees.

# AI Guidelines

When generating UI

Prioritize mobile.

Reuse existing components.

Maintain visual consistency.

Avoid introducing new design patterns unless they improve the existing experience.

Every new feature should feel like a natural part of the application.
